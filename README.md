# 语文小教练

部编版《语文》四年级上册的字词练习。**纯前端、零部署、零成本、离线可用**。

核心流程：**看拼音 → 在田字格里手写 → 交给家长批改 → 按间隔复习。**

---

## 为什么是"手写 + 家长批改"，而不是自动判分

这是被技术现实逼出来的选择，但结果反而更好。

**两件做不到的事：**

1. **网页没法强制调出手机的手写输入法。** `inputmode` 只有 `text / numeric` 等值，**没有 handwriting**——用哪种输入法由系统决定，网页切换不了。
2. **网页自己识别手写代价太大。** 要么内置几十 MB 的识别模型（离线就废了，老机器也扛不住），要么接在线 OCR（要密钥、要联网、有费用，还得把孩子写的字传到别人服务器上）。

这些都和「零成本、纯前端、离线可用」冲突。

**所以改成家长批改。好处是：**

- 孩子**真的在手写**，是"产出"而不是从候选字里挑的"再认"——这正是训练的目的
- 家长看到的是孩子**真实写的那个字**，能看出笔画错、结构歪、少个偏旁。这是自评看不到的，也是识别程序判断不准的
- 批注会跟着这个词存下来，下次复习时重新显示给孩子看

## 流程

### 孩子端

1. 首页**先选单元、再选课时**（第几课 + 课文标题都显示出来，跟课堂进度走）
2. 显示拼音 → 在田字格上用手指写
   - 田字格会自动折行：1~3 个字一行，**4 个字排成 2×2**，5 个字以上每行 3 个
     （四个字并排会窄得没法写）
3. 点「写好了」
   - **不显示答案**。一显示就变成自评了，那还不如直接对答案抄
   - 笔迹（按"点"存）+ 词语 + 时间 → 进"等家长批改"队列

### 家长端（有口令）

首页最下面「家长批改」→ 第一次进来先设 4～6 位数字口令。

- 逐条看：题目（拼音）+ **孩子真实笔迹的回放** + 正确答案
- 点「写对了 / 写错了」，可写批注（如"崩少了山头"）
- 批完 → 出队、进历史、安排下次复习日期

**口令的作用**：挡住孩子自己进去点"全对"。它不防外人，所以不加密、不做找回——忘了就清数据重设。

### 批改之后：马上给反馈，错的当天订正

**为什么不等到下次复习才告诉他？**
错的字拖几天才纠正，孩子这几天里很可能已经把错的写法记牢了——**错误先入为主，
纠正的成本比当时改高得多**。而且家长那句批注（"崩少了山字头"）当时看才有上下文，
隔几天他早忘了自己当时是怎么写的。

所以：

- 批改完 → 首页立刻出现「家长刚批改了 N 条」，列对错 + 批注 → 点「知道了」清掉
- **写错的字当天就到期**（不是等到明天），下次打开就能订正
- 写对的字才往后推：**第 1 → 2 → 4 → 7 → 15 天**

⚠️ 有个要注意的：看到反馈后**别让孩子立刻照着正确答案再描一遍**（那变成抄）。
先看批注想清楚错在哪，稍后再写。

### 间隔复习（这个模块的重点）

生字最怕的就是"今天会写、下周就忘"，所以**练多少次要，什么时候再练一次才关键**。
出题时**到期的排在最前面**——这是间隔复习真正起作用的地方。

## 数据

`js/data.js` 由脚本生成，**不要手改**：

- 来源：`01_学习资料库/02_同步资料/四年级上册/语文/单元知识要点与拓展.md`
  里的**写字表 / 词语表 / 多音字 / 易错字**，逐单元摘录到 `data/words.raw.json`
- 拼音由 `pypinyin` 生成后**写死**进 `data.js`，运行时零依赖
- 改内容请改 `data/words.raw.json`，再跑：`npm run gen-data`

目前：8 单元 / 240 个一类字 / 208 个词 / 263 个二类字（识字表）/ 每单元多音字 + 易错字提示。

## 开发

```bash
npm test          # 15 条冒烟测试
npm run gen-data  # 重新生成带拼音的字词数据
```

也可以直接双击 `index.html`（用的是普通 script，不是 ES module）。

## 功能

- **练**：看拼音 → 田字格手写 → 交家长批改 → 间隔复习（详见上面"流程"）。
- **资料（只读查阅）**：首页「二类字 / 多音字 / 易错字」一栏，按单元看：
  - 二类字（识字表，只认不写，按课时列出，带拼音）
  - 多音字（每个字列出不同读音和课文里的例子）
  - 易错字提醒（部首、笔画、形近字辨析）

## 已知限制

- **得在同一台设备上批改**：孩子用平板写，家长拿同一台平板批。要跨设备就得联网同步，那是另一个量级的事。
- **没批改的题不计入统计**：不然"做了但没批"会把数据搅浑。首页会显示"有 N 条等家长批改"，不会漏。
- **练习目前只有"看拼音写字词"一种题型**。资料查阅是只读的，不进练习、不进掌握度统计。
- 笔迹按"点"存，换设备/清数据就没了。
